# sailing_log

L 的航海主题个人主页。项目入口为 `/sailing_log/`，内容、素材、动画和测试集中在本目录，避免与另一位作者的主页耦合。

## 本地运行

在仓库根目录执行：

```sh
pnpm --filter portfolio-web dev --host 127.0.0.1 --port 5175
```

打开 `http://127.0.0.1:5175/sailing_log/`。正常页面使用浏览器原生滚动；`?debug=1` 可显示调试进度条。首页 `/` 当前重定向到本项目。没有执行发布、提交或推送。

## 当前内容

1. `Sailing Log` 与等宽小字 `Hi, this is L's site` 位于右侧，按字符从左到右显现，延续已确认的慢 0.2 秒节奏。
2. 细密字符组成单筒望远镜，镜筒接缝颜色更深，横向转动并放大进入目镜。
3. 字符海洋、白色浪花、少量灰色流云与随机字符小岛；小岛底边对齐海平线。
4. 镜内初始视角较前版拉远，海洋和岛屿在当前视角下直接重绘清晰字符；继续滚动时，同一画面向小岛放大，同时字符逐渐四散，露出纯白背景；反向滚动可回退。
5. 白色介绍页左侧逐行显示用户提供的文字，右侧两张路飞字符画交替出现：每张收拢 1.5 秒、完整停留 1 秒、扩散 1.5 秒，再切换下一张。文字不会随图片切换而重播。

人物使用用户最终提供的 `assets/luffy-source.png`，保留草帽、黑色衣服、脸部、两个台词框及原台词。未使用早期不完整的 AI 抠图，也没有重新生成面部或裁掉衣服。

第二张来自用户提供的 `assets/luffy-alternate-source.jpg`，只对字符采样数据排除外侧白底与下方黑色矩形背景，保留头发、草帽和伸出的手，原 JPEG 不变。两张字符画使用同一蓝色 `#184D97`。第一张图像范围保持用户设置的画布宽度 35%，第二张独立使用 39% 的范围并等比适配，实际宽约 38.16%；两张共用横向中心，文字从左侧 5% 移至 12%。

## 结构与调整

| 文件 | 用途 |
| --- | --- |
| `SailingLog.vue` | 自己的页面结构、素材加载与生命周期 |
| `sailing-log.css` | 仅以 `.sailing-log` 为范围的样式 |
| `scene.js` / `scene.d.ts` | Canvas 绘制与 GSAP/ScrollTrigger 生命周期；类型化的公共接口 |
| `motion.ts` | 滚动分段、放大与碎散叠加、轮廓内字符流动、人物收拢 |
| `portrait-renderer.ts` | 人物和台词分区绘制，直接绘制清晰字形，不使用中间人物贴图 |
| `portrait-flow.ts` | 向下的字符流、原图细线采样和台词区域选择 |
| `portrait-cycle.ts` | 两张人物图的收拢、完整停留、扩散和循环切换 |
| `assets.ts` / `types.ts` | 本地素材加载、校验与数据类型 |
| `assets/` | 望远镜帧、人物明暗采样及用户原图 |
| `scripts/` | 可选的离线素材生成工具（numpy/Pillow） |
| `reference/character-flow.mp4` | 用户提供的约 1.13 秒字符流动参考，不随网页加载 |
| `reference/prototype.html` | 迁移前预览快照，仅作设计存档，不是运行入口 |
| `__tests__/motion.spec.ts` | 放大/碎散同时发生、回退、密度保持、人物收拢测试 |

当前配色：望远镜与介绍页人物 `#184D97`，海洋 `#1888BF` / `#34B8C5`，岛屿 `#F6D081`。人物的深浅由同一蓝色的透明度和字符密度表现。

按用户最新确认，人物不再保留静止的边界层：所有字符从上向下连续移动，轮廓、五官和台词处也参与流动；通过移动位置的原图采样保持整体图案。之前用于固定边界的 `isFlowInterior` 已移除。

人物不再使用中间画布贴图：每帧直接按当前尺寸和屏幕像素比绘制字形。主体使用 120 列，两个台词框独立使用 384 列；主体字形更易分辨，台词则用更小、更密的字符保留日文笔画。原图明暗采样为 640×326，并从原图白色封闭区域提取两个台词框掩码，原图文件不变。

望远镜字符集与流动速度在 `motion.ts` 的 `flowingGlyph` 中调整；人物在 `portrait-flow.ts` 的 `portraitFlow`、`portraitStreamGlyph` 中调整。`TIMING` 的 `portraitGatherSeconds` / `portraitHoldSeconds` / `portraitScatterSeconds` 分别控制人物收拢、停留和扩散时间。图像尺寸与共用中心在 `scene.js` 的 `drawAbout` 中调整，文字位置在 CSS 的 `.sl-about` 内调整。海洋碎散仍为约 2.2 秒，`advanceProgress` 限制快速滚动跨过碎散区间的速度。

开发环境沿用已有 Vue/Vite；GSAP 通过 npm 本地依赖打包，数据由本应用提供，没有 CDN 脚本、Codex 专用状态或 iframe 依赖。离开路由时会释放 GSAP、观察器和动画循环；后台标签页暂停绘制，减少动态偏好下停用持续字符流动。
